# 人生可能 · AI 100+ 人生计划

**下载、解压、双击 `index.html`，即可开始使用。**

这是完整的中文离线人生目标管理应用。无需账号、API 密钥、服务器、Node.js 或 Python；使用现代桌面浏览器即可运行。代码、样式与图形都在一个 HTML 文件中，可断网使用。

## 立即使用

1. [下载离线运行包](https://github.com/lxrhillboy/life-ai-100-plugin/raw/refs/heads/main/downloads/Life-AI-100-Offline-v2.0.0.zip)，或到 [下载目录](downloads/) 点击 ZIP 文件的下载按钮。开发者也可使用 **Code → Download ZIP** 获取完整源码。
2. **先解压** ZIP，打开解压后的文件夹。
3. 双击 **`index.html`**。如果默认用编辑器打开，请右键选择浏览器。
4. 点击“新建目标”，开始管理自己的计划。

普通用户只需要 `index.html`，复制这个文件也可以分发完整应用。请放在固定文件夹，使用同一个浏览器打开。

## 现在可以做什么

| 功能 | 使用方式 |
| --- | --- |
| 收集人生目标 | 记录描述、过去的障碍、AI 帮助、预算、预计成果、下一步和日期 |
| 分类与筛选 | 十类生活领域，六个阶段，搜索与排序 |
| 优先 10 件 | 根据人生价值、兴趣、AI 帮助、成本、可行性和 30 天进展评分比较 |
| 调整偏好 | 六项权重可调；成本反向计分，已完成与暂缓目标不参与排序 |
| 30 天行动 | 为已选定和进行中的目标编写、勾选任务 |
| 进度与证据 | 手动维护进度，记录完成证据和资料链接 |
| 持续复盘 | 保存多条带日期的复盘 |
| 快乐 4 维度 | 标记成就感、情绪安定、适度挑战与人际连接，供个人反思 |
| 备份与迁移 | 导出 JSON，换设备后合并导入；支持 CSV 目标清单 |
| AI 辅导 | 生成包含当前目标、任务和最近复盘的提示词，手动复制到 ChatGPT |

首次启动没有个人数据。“看看示例灵感”可以添加三个通用示例，示例不会当成你已经决定实施的计划。

## 数据与 AI

- 数据留在**当前浏览器的本地存储**。程序不上传目标，不连接作者私人网站。
- 请定期“导出备份”，确认 JSON 已下载。清理浏览器、隐私模式、移动 HTML、换设备或浏览器，都可能让原记录不可见。先导出，后迁移。
- 导入仅支持本应用 v2 格式，最大 5 MB / 5000 个目标。相同 ID 保留更新时间较新的一份，其余目标保留；偏好沿用本机设置。
- AI 采用**手动复制到 ChatGPT**的方式，不内置模型，不自动调用 API。发送前由你审阅内容。
- 没有自动跨设备同步；程序关闭后不发送通知。快乐 4 维度不是医学诊断或精确因果模型。

详细步骤见 [使用说明](docs/USAGE.md)。

## 开发与验证

直接修改 `index.html` 并重新打开。可选用 `python -m http.server 8765` 启动本地预览，再打开 `http://127.0.0.1:8765`。HTTP 地址与直接打开文件的记录通常不共享，可用 JSON 迁移。

开发者如已安装 Node.js，在仓库根目录执行：

```sh
node tests/run-tests.cjs
```

测试涵盖导入格式、重复 ID、加权排序、排除已完成目标、任务保存、备份往返、合并、文本转义、AI 提示词和无外部依赖。
