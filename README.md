# 人生可能 · AI 100+ 人生计划

用 AI 把曾经的想法变成可实现的生活：收集、筛选、启动与持续复盘，100 件是起点。

**本仓库公开的是当前 ChatGPT 插件的配置源码。网站前端、MCP 服务实现、数据库与完整部署源码不在此版本中。下载本仓库不能独立运行整套人生计划系统，也不会自动获得原服务的访问权限。**

## 项目用途

该插件连接一个人生目标管理服务，帮助用户收集目标，记录分类、实施障碍、AI 帮助、下一步行动，以及推进与复盘。

当前连接所暴露的工具包括：

| 工具 | 用途 |
| --- | --- |
| `life_plan_overview` | 查看优先目标、进行中的计划、复盘和偏好 |
| `list_life_goals` | 按分类、阶段和分页查看目标 |
| `get_life_goal` | 读取一个目标的完整记录 |
| `add_life_goal` | 按用户要求增加目标 |
| `update_life_goal` | 按用户明确反馈更新目标 |

以上是现有服务的功能说明。对应业务实现未包含在本仓库。
