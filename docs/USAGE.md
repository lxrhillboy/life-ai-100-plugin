# 下载后的使用说明

## 第一次打开

下载 ZIP → 解压 → 双击 `index.html` → 点击“新建目标”。无需安装或运行命令。

建议在电脑上使用现代浏览器。手机文件预览器可能不执行 HTML 脚本，桌面端是本版本主要使用方式。

第一次打开没有个人目标。可点击“看看示例灵感”，再编辑或删除示例。

## 记录并推进一个目标

1. 新建目标，写下名称、描述与期望成果。
2. 记录过去的障碍，以及 AI 可以提供的帮助。
3. 给六项指标打 1–5 分。成本越高代表负担越大，排序时反向计算。
4. 写下下一步和 30 天任务，每行一个任务。
5. 确定启动时，将阶段设为“已选定”或“进行中”。
6. 勾选任务，记录证据与复盘。编辑时可手动调整进度。
7. 确认完成时，将阶段改为“已完成”。

任务数与手动进度独立。勾选任务不会自动将整个目标标为完成，阶段由你决定。编辑时相同文字的任务保留勾选状态，文字改动会生成新任务。

## 优先 10 件

未完成且未暂缓的目标参与排序。优先分 = 六项评分的加权平均 ÷ 5 × 100，其中成本使用 `6 - 成本评分`。

“偏好与帮助”可调权重。分数反映你的主观比较，不是客观 AI 评估，也不代表承诺。

## AI 辅导

在目标详情点击“生成 AI 辅导提示词”，检查后复制到自己的 ChatGPT 对话，主动发送。程序不调用模型、不要求 API 密钥，也不主动发送记录。

如果自动复制受限，程序会选中文字，按 Ctrl+C（Mac：Command+C）即可。之后手动把 AI 建议写回目标。

## 保存与备份

保存目标、勾选任务、保存复盘或改权重后，程序将记录写入浏览器本地存储。黄色提示表示写入失败或多标签页冲突，请先导出备份，勿直接关闭。

点击“导出备份”会发起 JSON 下载，浏览器可能询问保存位置，请确认文件保存成功。推荐每周一次，重要修改后另备份一次。

清理浏览器、移动文件、换浏览器、隐私模式或新设备，都可能看不见旧记录。先在旧位置导出，再在新位置导入。HTML 本身不包含你之后输入的目标。

CSV 用于阅读分析；完整恢复请用 JSON。CSV 会对可能被识别为公式的开头字符做文本处理。

## 导入 JSON

选择本应用 v2 导出的 JSON，检查合并摘要后确认。相同 ID 保留更新时间较新的一份，其他目标保留；偏好沿用本机设置。

单文件限 5 MB，单次和合并后最多 5000 个目标。跨设备时间错误会影响“较新”的判断，导入前建议导出本机备份。

原网站数据库或其他程序的导出不属于此格式，不能直接导入。离线版不会主动读取原网站。

## 常见问题

**打开后是代码？** 用浏览器打开 `index.html`，不要用记事本。先从 ZIP 解压。

**关闭重开后没有记录？** 确认同一浏览器、同一文件位置，未用隐私模式。用备份恢复。不同浏览器对本地文件存储的行为可能不同；无法写入时程序会提示。

**能同步到 ChatGPT 插件吗？** 不能自动同步。这是独立离线应用。原远程配置保存在 `integrations/original-remote/` 供参考。

**作者能看到我的内容吗？** 此程序没有上传接口和统计代码。打开外部资料链接、主动向 AI 发送内容时，由你决定是否共享。

**需要付费吗？** 程序没有内置收费或付费接口；外部 ChatGPT 等服务有各自的使用条件。

**有自动提醒吗？** 仅显示目标日期，程序关闭后不推送通知。

**如何升级？** 先导出备份，再打开新版本；需要时导入 JSON。
