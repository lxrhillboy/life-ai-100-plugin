# 下载与复用说明

## 1. 下载配置源码

在仓库首页选择 **Code → Download ZIP**。本仓库没有需要安装的运行依赖，也没有启动命令，因为它仅包含远程插件的配置文件与文档。

解压后请显示隐藏文件，以查看 `.app.json` 和 `.codex-plugin` 目录。

## 2. 理解服务依赖

`plugin.json` 通过 `apps` 字段引用根目录的 `.app.json`；后者引用平台上已经注册的应用。真正的目标管理、数据库读写与工具执行发生在远程服务中。

复制这些文件不会复制服务，不会复制数据库，也不会改变原服务的用户授权。原服务可以是仅限所有者访问的服务。

## 3. 复用为自己的项目

1. 阅读现有配置，了解展示信息与应用引用方式。
2. 实现自己的目标管理后端和 MCP 工具，并配置身份认证及数据访问控制。
3. 在目标平台完成自己的应用注册，取得自己的应用连接配置。
4. 替换应用引用及插件名称、作者、说明与网站地址。
5. 在支持的客户端中按其当前文档测试和安装。

如果要使用 GitHub marketplace 分发、完整网站部署、跨用户数据隔离或官方目录上架，需要额外实现与验证。此配置源码版本未包含这些能力。

## 4. 验证范围

公开整理时已核对两份原始配置文件，验证 JSON 可解析，以及 `apps` 指向的文件存在。发布副本采用逐项文件清单，不包含凭据或用户目标数据。

没有使用新的第三方账号验证安装、身份认证或完整业务流程，因此不能把配置检查视为独立部署验证。
